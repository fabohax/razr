First public Razr release: a read-only OKX spot BTC/USDT 1m MACD monitor with a Linux desktop GUI.

### Included

- Confirmed closed-candle signals, UTC validation, warm-up and chronological recovery.
- SQLite event identity, EMA checkpoints and persistent per-channel delivery retries.
- Full-screen GUI with 20-point logs, health display, bounded output and graceful shutdown.
- Desktop alerts and PipeWire/PulseAudio/SoX sound adapters.
- Optional GUI login startup or a headless systemd user service with boot support.
- Deterministic offline replay, optional long-only historical simulation and CI verification.

### Linux download

Download `razr-v0.1.0-linux-x86_64.tar.gz`, extract it, then run:

```bash
tar -xzf razr-v0.1.0-linux-x86_64.tar.gz
cd razr-v0.1.0-linux-x86_64
./razr-gui
```

Python and the public config template are bundled. The default GUI creates configuration in your per-user Razr data directory; no API keys are required. Press Esc to leave full screen. Click Run Bot to start monitoring.

A standalone executable is also attached; run `chmod +x razr-gui-v0.1.0-linux-x86_64` after downloading. Verify downloads against `SHA256SUMS.txt`. The archive includes installation instructions, license, example configuration and release verification status.
